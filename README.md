# Harbourline Creative: Case Facilitation Toolkit

BADM 470 case facilitation (Capilano University). A runbook for the facilitators and class-facing slides for a 90-minute, discussion-based facilitation of the Harbourline Creative case, structured around the abbreviated case analysis process in Chapter 2 of Anderson, Buengel, & Simpson (2025).

## Files

- `index.html`: facilitator runbook (run of show, activities, probing questions, timers, notes)
- `slides.html`: class-facing slides with live boards, polls, bonus rounds, group scoring and winner reveal
- `README.md`: this file

## Publish with GitHub Pages

1. Create a new public repository named `harbourline-facilitation`.
2. Choose **uploading an existing file**, drag in `index.html`, `slides.html` and `README.md`, and click **Commit changes**.
3. Go to **Settings > Pages**, set Source to **Deploy from a branch**, choose **main** and **/ (root)**, and click **Save**.
4. After a minute or two, open:
   - Runbook: `https://YOUR-USERNAME.github.io/harbourline-facilitation/`
   - Slides: `https://YOUR-USERNAME.github.io/harbourline-facilitation/slides.html`

## Slide shortcuts

Arrow keys or space move between slides. T starts the timer, R picks a voice, G opens groups and scoring, F toggles full screen.

## Academic integrity

AI (Claude, Anthropic) was used as a support tool to draft these materials. Verify them against the case and Chapter 2, and cite AI use in your submission. The bonus-round formats were inspired by a shared web page, Harbourline: The Strategy Challenge (meetgoyani5.github.io); the questions were rewritten from the case facts.

Anderson, L., Buengel, D., & Simpson, J. J. (2025). *Strategic management and case analysis: An integrated approach.* Virginia Tech Publishing. https://pressbooks.lib.vt.edu/strategicmanagementandcaseanalysis/
